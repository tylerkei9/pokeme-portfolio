About this project

Click to hide

My personal portfolio website, built as a playable Pokémon Black & White style game. I wrote the 3D engine from scratch in strict TypeScript on Three.js, and every building and object is built and painted in code, so the site ships no 3D model files. The engine, the React interface, and the area data stay in separate layers that talk through a small shared state, which is why adding a new area or exhibit means editing data rather than engine code.

Stack: TypeScript, Three.js (WebGL), Canvas 2D, React, Zustand, Vite, Tailwind CSS
