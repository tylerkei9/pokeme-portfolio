How I built PokéMe

Every area in this game is a short data file: a grid of letters for the ground, plus a list of buildings and objects. The engine I wrote turns that data into the 3D world you walk through. Pick an area below and hover any square to see the data behind it.

About this project

Click to hide

My personal portfolio website, built as a playable Pokémon Black & White style game. I wrote the 3D engine from scratch in strict TypeScript on Three.js: a game loop, tile movement and collision, a camera per area, and billboarded sprites. No 3D models were used. Every building and object is built and painted in code when the game loads, which keeps the game code to about 240 KB.

Stack: TypeScript, Three.js (WebGL), Canvas 2D, React, Zustand, Vite, Tailwind CSS
