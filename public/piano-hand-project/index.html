About this project

A motion planner that decides how a robotic hand moves across a piano keyboard to play a song. For each note it weighs every possible hand position and picks the sequence that plays the whole piece with the least strain and movement. Built as Algorithms Team Lead for Purdue Autonomous Robotics (team of 4), where split point optimization cut hand movement 35% versus static assignment. The dashboard walks through each song note by note, showing the positions considered and the one chosen, with synced playback.

Stack: Python, Viterbi dynamic programming, music21, JavaScript
